# 🛒 Green Shopping

**Green Shopping** is a decentralized e-commerce platform built on the Stellar blockchain. It focuses on eco-friendly products and allows users to buy and sell in a transparent and secure way. Powered by smart contracts developed with Soroban and its native token, **GreenShoppingToken (GST)**, the platform ensures trustworthy transactions and a visible supply chain. Users can connect their Freighter wallet, explore a catalog of sustainable goods, and make purchases directly using GST. The responsive web interface is built with modern tools like **React** and integrates Stellar SDK to interact with the blockchain. Green Shopping promotes responsible consumerism by combining blockchain transparency with environmental values.

## Our Vision

Green Shopping aims to build a future where sustainable shopping is easy, transparent, and trusted by everyone. By using blockchain technology, we ensure that every product’s journey is traceable, every transaction is secure, and every purchase supports eco-friendly choices. We believe in empowering people to shop with purpose and help the planet at the same time. Our goal is to create a global marketplace where green products are not only accessible but encouraged through smart, honest technology — making a real impact on how people buy, sell, and think about sustainability.

## 🌟 Key Features

- ♻️ Eco-friendly product catalog

  A curated selection of sustainable products from verified sellers.
  
- 🔐 Secure smart contracts via Stellar Soroban

  All transactions are handled by **Stellar Soroban**, ensuring transparency and trust.
  
- 🪙 Shopping with GST token

  Seamless payments using the **GreenShoppingToken (GST)** for both buyers and sellers.
  
- 📦 Transparent supply chain and purchase history

  Every product's lifecycle and transaction history is verifiable on-chain.
  
- 💳 Wallet connection (Freighter supported)

  Connect your **Freighter Wallet** for secure and direct interaction with the dApp.
  
- 🌍 Responsive and modern web interface

  A sleek UI built with modern web standards for both desktop and mobile users.

## 🖥️ Frontend Web Application

The front end of Green Shopping is designed with user experience in mind. It is fully responsive, intuitive, and optimized for fast interactions with blockchain components. Users can:

- Browse eco-products by category or popularity

- View detailed product and seller profiles

- Connect wallets and make purchases with GST

- Track their order and token transaction history on-chain
