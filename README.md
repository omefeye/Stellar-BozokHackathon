# 🛒 Green Shopping

Green Shopping is a blockchain-based shopping platform where eco-friendly products can be bought and sold in a transparent, trustworthy, and decentralized environment. This project operates on the Stellar network using smart contracts developed with Soroban and its native token, **GreenShoppingToken (GST)**.


https://stellar.expert/explorer/testnet/contract/CCXWG5NIXW67Y44PL5PQ7FF67R74VGPR4ZCWBOMH4JADZYRNXBNXHH3P

## 🌟 Key Features

- ♻️ Eco-friendly product catalog
- 🔐 Secure smart contracts via Stellar Soroban
- 🪙 Shopping with GST token
- 📦 Transparent supply chain and purchase history
- 💳 Wallet connection (Freighter supported)
- 🌍 Responsive and modern web interface

---

## 🧰 Technologies Used

React, Stellar Soroban, Rust, Stellar SDK, Freighter
